# Lost-and-found-smart-matcher
Developed a Lost &amp; Found Smart Matcher System using HTML, CSS, and JavaScript with features like smart item matching, user authentication, admin approval, claim management, notifications, and reward points.
The Lost & Found Smart Matcher System is a responsive web-based application developed using HTML, CSS, and JavaScript to help users efficiently report, search, and recover lost or found items. The system provides a smart matching mechanism that compares item names, categories, descriptions, and locations to identify potential matches between lost and found reports. It includes secure user authentication, admin moderation, claim verification, notifications, reward points, dark mode support, image uploads, dashboard analytics, and search/filter options for a better user experience.

#How It Works

Users can register and log in to the system, then report lost or found items by providing item details such as name, category, description, date, location, and image. The smart matching system analyzes reports and generates possible matches with similarity scores. Users can submit claims for found items, while admins can review reports, manage users, approve claims, and moderate suspicious content. Notifications and reward points encourage active participation and successful item recovery.
